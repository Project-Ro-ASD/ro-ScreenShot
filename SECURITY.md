# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
If you discover a security vulnerability within Ro-ScreenShot, please report it confidentially by contacting the Project Ro-ASD team at `sopwith.osdev@gmail.com` rather than opening a public issue.
